# Changelog

User-facing release notes are published with each
[GitHub release](https://github.com/zeekrey/wiesel/releases).

- **Preview:** tags ending in `-pre`, marked as prereleases.
- **Stable:** numeric tags without `-pre`.

Notes are collected from the required `Release Notes:` section in included PRs
and reviewed before publication. See [CONTRIBUTING.md](CONTRIBUTING.md) for the
preview/stable release train workflow.
